GLOWCARE - SKINCARE SHOP COLLEGE PROJECT
==========================================

FILES:
- index.html
- style.css
- script.js
- assets/ (put your own product/website images here)

HOW TO ADD IMAGES:
1. Open the "assets" folder.
2. Put your images there using these exact names:

hero-skincare.jpg
about-skincare.jpg
cleanser.jpg
serum.jpg
moisturizer.jpg
sunscreen.jpg
facewash.jpg
hyaluronic.jpg
aloe.jpg
sunshield.jpg

3. Open index.html in Chrome.

IMPORTANT:
- This is a front-end college project using only HTML, CSS and JavaScript.
- Cart, filter, search and newsletter demo are included.
- Product prices/names are sample data. Change them in script.js.
- Change shop name, phone, email and address in index.html.
- No backend or real payment gateway is connected.
